# Style Showcase Hub

quero criar um site, para vendas de roupas, que tenha a area do adm e do usuario, que eu possa mandar o link para a pessoa via netlify

P: Como você quer que os dados (produtos, pedidos) funcionem no site?
R: Versão simples de demonstração (dados salvos só no navegador de cada pessoa, sem banco de dados)

P: O que a área de admin precisa fazer? (Selecione todas que se aplicam)
R: Só cadastrar/editar/remover produtos

P: Como o cliente vai finalizar a compra?
R: Carrinho + formulário que manda pedido por WhatsApp/e-mail (sem pagamento online)
